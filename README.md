# CP2077//FAN — фанатский сайт об игре Cyberpunk 2077

Учебный проект по курсу «Разработка пользовательского Web-интерфейса» (КубГУ, 2026).

Адаптивный (mobile-first) одностраничный сайт по собственным дизайн-макетам.

## Функциональность

- фоновое видео в шапке сайта;
- выпадающее меню по наведению (десктоп);
- полноэкранное мобильное меню с раскрывающимися подпунктами;
- слайдер медиа-галереи (автопрокрутка, стрелки, точки, клавиатура);
- FAQ-аккордеон;
- форма подписки: отправка без перезагрузки через fetch (formcarry), черновик полей в localStorage.

## Стек

HTML5, CSS3, ванильный JavaScript. Шрифты: Montserrat, Rajdhani, Share Tech Mono (Google Fonts).

Скриншоты и видеозапись сделаны автором в фоторежиме игры.
